Cara data digunakan

Data hanya digunakan untuk menerbitkan klip pemilik ke saluran pemilik. Tiada data pengguna lain dikumpul. Tiada data dijual, dikongsi atau digunakan untuk iklan.

Penyimpanan

Token akses Google disimpan secara peribadi pada komputer pemilik dan tidak didedahkan kepada pihak ketiga. Akses boleh dibatalkan pada bila-bila masa di https://myaccount.google.com/permissions.

Penggunaan data Google

Penggunaan maklumat yang diterima daripada Google API mematuhi Google API Services User Data Policy, termasuk keperluan Limited Use.
